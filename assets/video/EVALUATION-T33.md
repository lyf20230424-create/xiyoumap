## 三、生产路线可行性评估

**用户确认的生产路线**：
```
角色参考图 + 道具图 + 场景图（真实主体） + 线稿关键帧（构图控制） → AI 图生视频
```

| 环节 | 可行性 | 说明 |
|---|---|---|
| 主体参考图 | ✅ | 7角色/5道具/6场景已就绪 |
| 线稿构图控制 | ✅ | 8线稿PNG已就绪 |
| AI 图生视频 | ⚠️ | **Agnes 视频 API 角色参考不可靠**（实测未参考到图），生产需换其他模型（Sora/Runway 等） |
| 视频分辨率 | ⚠️ | Agnes 强制映射 720p/4:3，其他模型需验证画幅 |

**生产路线结论**：⚠️ 素材体系完备，但 **Agnes 不适合作图生视频生产**，需切换更成熟的视频模型。

## 四、成本评估

| 环节 | 成本 |
|---|---|
| 素材生成（7角色+5道具+6场景+8线稿） | 约 26 次图片 API 调用 |
| 程序化样片（animatic） | 0（HTML+Web Audio+浏览器TTS） |
| AI 图生视频生产 | 每镜头 1 次视频调用（Agnes 已试，换模型后重新估） |
| 全量 81 难 | 素材 ×81 + 视频 ×81，成本主要在看板+视频生成 |

**成本结论**：单难素材成本可控；**批量 81 难需先确定视频模型和每难预算**。

## 五、批量决策建议

### 结论：**先定生产模型，再做批量**

1. **立即**：第12难样片作为「模板难」——素材体系、分镜结构、线稿参考图、数据 schema 全部复用
2. **生产模型**：测试其他 AI 视频工具（Sora/Runway/可灵等）的图生视频角色参考能力，选定后固化 prompt 模板
3. **批量策略**：
   - 按难分组（v3.0 已定义 T27-T33 流程）
   - 每难产出：visual-elements.json + characters.json（追加角色）+ scenes.json + storyboard + 素材图 + 关键帧 + 线稿 + animatic
   - 批量顺序建议：按难号，优先名场面难（如 61-64 狮驼岭/47-49 火焰山）

### 数据管道已就绪
- `read-data.js`：程序化读取数据
- JSON schema 已稳定（characters/scenes/storyboard）
- 模板填充（沙僧演示成功）可批量生成新角色
