## 一、数据结构设计（推广到全部 81 难）

每难一个 JSON 对象。字段说明：
- `characters[].role` 枚举：`protagonist`（主角师徒） | `boss`（本难妖怪） | `deity`（神佛） | `mortal`（凡人） | `minion`（小妖/随从）

### 色彩基调
- 主色：暗夜靛蓝（夜景）、水墨灰（山野）
- 强调：昏黄灯火（高宅）、猪八戒灰黑（角色）
- 对比：孙悟空金黄（金甲）、唐僧红金（袈裟）
- 整体：中国水墨 + 暗夜对比，喜剧感靠八戒的憨态动作呈现

### 关键镜头钩子（供分镜参考）
1. 悟空变作高翠兰、红盖头下露出猴脸 → 喜剧反转
2. 八戒背「新娘」上路，背上却是石头/悟空 → 经典桥段
3. 云栈洞前金箍棒 vs 九齿钉耙对撞 → 视觉高潮
4. 八戒被收服、弃钉耙跪地 → 情感落点
5. 师徒四人离庄、朝阳上路 → 结尾空镜
