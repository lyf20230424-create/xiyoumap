# 西游记取经路线地图可视化

## 项目简介

这是一个基于《西游记》文本内容创建的交互式取经路线地图可视化项目。展示了唐僧师徒四人从长安到灵山的完整旅程，包括各个地点、遇到的妖怪以及关键事件。

## 功能特性

### 1. 路线可视化
- 按取经先后顺序显示所有地点
- 使用不同颜色区分妖怪类型
- 路径动画效果，模拟取经旅程

### 2. 交互功能
- **点击地点节点**：查看该地点的详细信息，包括妖怪列表和关键事件
- **鼠标悬停**：显示地点简介
- **路径高亮**：悬停地点时高亮显示已走过的路线
- **缩放和平移**：支持鼠标滚轮缩放和拖拽平移地图

### 3. 搜索功能
- 在搜索框中输入地点名称或妖怪名称
- 匹配的节点会高亮显示
- 只有一个匹配结果时会自动显示详情

### 4. 响应式设计
- 适配不同屏幕尺寸
- 移动设备友好
- 自动调整地图大小和布局

### 5. 妖怪分类
- **精怪**（红色）：白骨精、黄风怪等
- **神仙/妖仙**（金色）：孙悟空、猪八戒等
- **动物**（绿色）：白龙马、六贼等
- **魔王**（紫色）：金角大王、银角大王等
- **其他**（灰色）：未分类的妖怪

### 6. 八十一难时间轴（v2.0）
- header「📜 八十一难」按钮 → 右侧滑出时间轴面板
- 依据第 99 回观音所念八十一难完整名单（难名 + 剧情）
- 顶部进度条显示当前第几难
- **与地图双向联动**：点地图节点 → 时间轴滚动到对应难度；点时间轴条目 → 地图跳转对应节点
- 地图节点右上角标注对应的难号

### 7. 妖魔族谱关系图（v2.0）
- header「🧬 妖魔族谱」按钮 → 居中弹窗展示 d3-force 力导向图
- 揭示西游暗线：妖怪多系神佛坐骑/童子/亲属下凡，最后由主人收服
- 5 类连边分色：出身（坐骑/童子）/亲属/降服/贬谪/师徒
- 48 节点全连通，孙悟空为枢纽；点带 📍 的妖怪节点跳转地图

### 8. 取经动态回放（v2.0）
- header「🎬 取经回放」按钮 → 底部控制条
- 主路径渐进绘制 + 金色取经队标记沿路径行进
- 逐节点点亮，到达妖怪站点触发红色爆裂动画 + 自动弹窗详情
- 倍速 1x/2x/4x、🎯 跟随平移、关闭复位

## 使用方法

1. 打开 `index.html` 查看完整的取经路线地图
2. 点击任意地点节点查看详情
3. 使用搜索框快速查找地点或妖怪
4. 鼠标滚轮缩放地图，拖拽平移视图
5. 点击地图右上角的缩放控制按钮进行精确控制
6. 点 header 右上角「📜 八十一难」查看取经难度时间轴
7. 点「🧬 妖魔族谱」查看妖怪与神佛的关系网络
8. 点「🎬 取经回放」动态播放取经全程

## 数据结构

每个地点的数据结构如下：

```javascript
{
    id: 1,                    // 地点ID
    name: "地点名称",          // 地点名称
    type: "地点类型",          // 类型：起点、终点、险境、村庄、国家等
    demons: ["妖怪名称"],     // 遇到的妖怪列表
    events: ["事件描述"],      // 关键事件列表
    position: {               // 在地图上的位置
        x: 100,
        y: 500
    },
    description: "地点简介"   // 详细描述
}
```
